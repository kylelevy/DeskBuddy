# `fab`

Fabrication files and assembly notes for the **Minimalist OLED 0.96" Modern Modular Cases** MakerWorld model.

- [`assembly-guide.md`](assembly-guide.md) — local Markdown assembly guide, including the old-screen fit requirement.
- `zips/` — place the downloaded MakerWorld ZIP archives here, then extract their contents alongside this README. The model downloads could not be retrieved anonymously because MakerWorld requires a signed-in session for file downloads.

## Old-screen fit requirement

For the old screen to work, use the **`0.96" old`** part in combination with the **full build plate scaled to 103% of its original size**.

Source: [MakerWorld model 2085334, profile 2591428](https://makerworld.com/en/models/2085334-minimalist-oled-0-96-modern-modular-cases#profileId-2591428).
